проверяем доступные выпуски…

установка

скачайте DMG, перенесите приложение в Applications и запустите его. первый пилот — для Mac с M-серией; минимальная версия macOS — 15.

разрешения

для глобального ввода нужны Accessibility и Input Monitoring. приложение объяснит выдачу разрешений; их можно оставить выключенными.

обновления

включите автоматическую проверку в настройках или выберите «проверить обновления». установка требует подтверждения. beta предназначена для пилота; stable получает проверенные стабильные выпуски.

удаление

завершите приложение, выключите его запуск при входе и переместите приложение из Applications в Корзину. личные настройки сохраняются отдельно от приложения.

приватность и поддержка

обработка файлов и текста выполняется локально. проверка обновлений обращается к GitHub и не отправляет ваши файлы или набранный текст. crash reporting первого пилота отключён. в сообщении об ошибке укажите версию, macOS и синтетический пример без личных данных.

исходники, лицензии и SHA-256 находятся рядом с установщиком каждого выпуска.
